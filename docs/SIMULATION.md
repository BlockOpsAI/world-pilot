# SIMULATION

## Use three fidelity levels

### Level 1 — Formal graph
Deterministic reachability, bypass, cycles, invariants, deadlocks.

### Level 2 — Synthetic profiles
Novice, impatient, curious, explorer, goal-driven.

### Level 3 — High-fidelity AI
Optional P2 for visual judgment and unusual behavior. Use few runs.
