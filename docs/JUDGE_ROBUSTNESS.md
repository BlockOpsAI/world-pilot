# JUDGE ROBUSTNESS

## Target
Minimum 50 prompts; stretch 100.

## Domains
- museum
- gallery
- showroom
- classroom
- training
- escape room
- retail
- Mars maintenance

## Categories
- CREATE
- PROGRAM
- SPATIAL

## Examples

```text
Create a museum with three exhibits and an exit.
Open the exit only after all exhibits are inspected.
When I enter here, turn this light on.
Nobody should reach the exit without inspecting all exhibits.
Open this.
```

The last prompt should clarify if context is insufficient.
