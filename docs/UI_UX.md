# UI / UX

## Principle
The 3D world is the primary interface.

## Layout
```text
Top: WorldPilot | Edit/Test | Undo/Redo
Main: large 3D viewport + small contextual inspector
Bottom: selected/pointed context + command bar
```

## Hide
- raw JSON
- internal IDs
- LLM prompt
- logs
- chain-of-thought

## Show
- `THIS → Battery B-17`
- `HERE → Zone 2`
- human-readable trigger/actions
- evidence
- PASS/FAIL

## Trust UX
```text
WorldPilot understood:
WHEN Battery enters Zone 2
DO Warning + Reset

[Apply] [Edit] [Cancel]
```
